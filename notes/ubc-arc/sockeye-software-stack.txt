 

A complete catalogue of the software available on Sockeye
In Sockeye, use the 'module spider' command to navigate the software collection currently loaded. There are three modes:

0: "module spider":                                   Reports all modules, similar to module avail.
1: "module spider <name>":                    Reports all versions for the modules that match <name>.
2: "module spider <name/version>":  Reports information on a particular module <name/version> including the packages it depends on.

Software Collections
The following tables provide complete, alphabetical lists of the software packages available on Sockeye for each main collection. The Default collection is already loaded when you are logged into Sockeye, but any other collection(s) must be loaded manually. 

ai: artificial intelligence
bio: bioinformatic libraries & apps
chem: chemistry libraries & apps
geo: geography libraries & apps 
io: input/output software
m: MPI implementations
math: mathematical libraries
 phys: physics libraries & apps
t: tools for development 
  vis: visualization software
