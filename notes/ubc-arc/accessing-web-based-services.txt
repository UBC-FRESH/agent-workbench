Accessing Web-Based Services in Your Jobs
Pages… Running Jobs
Created by Nesrallah, Michael, last updated by Fletcher, Chad on Jul 16, 2026  2 minute read
Overview
Loading the HTTP Proxy Module
Available Web Services
Prerequisites

In this guide, it is assumed you know how to connect to Sockeye, navigate its filesystem, load modules, and write job scripts. If you are not familiar with Sockeye, you should review the Quickstart Guide and Running Jobs pages.
Overview
By policy, the compute nodes on Sockeye do not have internet access. However, we understand that there are web-based services that may be helpful to use during a job. For example, the Weights & Biases tool is useful in machine learning jobs to keep track of metrics and for model management and visualization. This guide will walk you through how to access ARC-approved web-based services in your jobs.

Loading the HTTP Proxy Module
In order to use a web-based service in your jobs, you'll need to load the module, http_proxy, which acts as an intermediary between the compute nodes and the Internet:



module load http_proxy


This command may be incorporated into your job script just like any other module, i.e.



#!/bin/bash
 
#SBATCH --time=xx:00:00          # Request xx hours of runtime
#SBATCH --account=alloc-code     # Specify your allocation code
#SBATCH --nodes=x                # Request x nodes
#SBATCH --ntasks=x               # Request x tasks (~x cpus assuming cpus-per-task=1)
#SBATCH --mem=xG                 # Request x GB of memory
#SBATCH --job-name=job_name      # Specify the job name
#SBATCH --output=output.txt      # Specify the output file
#SBATCH --error=error.txt        # Specify the error file
#SBATCH --mail-user=<your-email> # Email address for job notifications
#SBATCH --mail-type=ALL          # Receive email notifications for all job events
  
# Load necessary software modules
module load http_proxy 
module load <other software packages...>

cd $SLURM_SUBMIT_DIR 

#<executing commands here>
Available Web Services
Outbound access is controlled by policy and the following is a list of what is currently permitted by the HTTP proxy:

wandb.ai - Weights & Biases
api.colabfold.com - Protein Folding
www.comet.com - Comet
huggingface.co - Hugging Face
openai.com - OpenAI
gbif.org - Global Biodiversity Information Facility
googleapis.com - Google APIs Gateway
accounts.google.com - Google Authentication
cibersortx.stanford.edu - CIBERSORTx 
If there is another web service that you would like to use in your Sockeye jobs, reach out to us at arc.support@ubc.ca and we will look into your request.
